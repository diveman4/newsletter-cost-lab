How we verify prices (and how we'll test platforms)

Price verification

  1. Prices are read from each vendor's own public pricing page, at every list size the page's own slider offers, for both yearly and monthly billing where shown.
  2. Each price is stored with the date it was checked. The current data was checked on 2026-11-14.
  3. Where a vendor only states a discount (for example "2 months free" on yearly billing), we calculate the other price and say so.
  4. Where we couldn't verify a number, we show "–" instead of guessing.
  5. Prices are re-checked regularly, and every change is recorded in the price change log.

Fixed-task platform tests (coming soon)

Price is only half of the decision. We're preparing a repeatable test that runs the same tasks on each platform's free plan, with the same inputs, and publishes the raw results:

  1. Time to go from sign-up to a sent first issue.
  2. Build and embed a sign-up form on a test page.
  3. Send an identical issue to a fixed set of test inboxes (Gmail, Outlook, Yahoo) and record inbox, promotions or spam placement.
  4. Import and export a test list of 100 addresses, and check what's kept.
  5. Set up a 3-email welcome sequence where the free plan allows it.

Results will be dated, repeated on a schedule, and published with what went wrong as well as what worked. We won't claim to have tested anything until a test has actually been run.
