# 実際に使ってみるテスト：手順書（TAさん用）

目的：各サービスで「同じ作業」をして、結果をそのままサイトに載せる。
他の料金比較サイトにはない、このサイトだけの情報になる。

## ルール

- テストするのは TAさん本人。結果は見たまま・感じたままを書く（盛らない、悪い点も書く）。
- アフィリエイトの有無に関係なく、同じ手順で公平にやる。
- 送信先は自分のメールアドレスだけ。他人のアドレスは使わない。
- アカウントは TAさん自身が作る（Claude はアカウント作成・ログインをしません）。
- 1サービスあたり 45〜60分が目安。1日1サービスでOK。

## 順番（おすすめ）

1. Kit（無料プラン）
2. beehiiv（無料プラン）
3. systeme.io（無料プラン）
4. MailerLite（無料プラン）
5. Substack
6. 余裕があれば Buttondown（無料は100人まで）。Ghost は無料プランがないので後回し。

## 準備（最初に1回だけ）

- テスト用の受信箱：Gmail（必須）。Outlook.com / Yahoo メールがあれば追加（なくてもOK）。
- テスト用の連絡先10件：Gmail の「+」付きアドレスを使う。
  例：`yourname+t1@gmail.com` 〜 `yourname+t10@gmail.com`（全部自分の Gmail に届く）。
  これを1列のCSVファイル（`email` という見出し＋10行）にしておく。
- テスト用の記事：短い文章（タイトル＋3段落＋画像1枚＋リンク1つ）を1つ用意して、全サービスで同じものを使う。
- ストップウォッチ（スマホでOK）。

## 作業と記録すること

### 作業1：登録から最初の配信まで
- サービスの登録ボタンを押した時点で計測スタート。
- 用意した記事を作って、自分の Gmail に送信できた時点でストップ。
- 記録：**かかった分数**、途中でつまずいたこと。

### 作業2：登録フォーム
- そのサービスで読者登録フォームを作り、どこかに埋め込む（サービス内のランディングページでもOK）。
- 記録：**できたか / かかった分数**、メモ。

### 作業3：届いた場所
- 作業1で送ったメールが、各受信箱のどこに届いたか。
- 記録：Gmail = メイン / プロモーション / 迷惑メール。Outlook・Yahoo も同様（未テストなら「未テスト」）。

### 作業4：取り込みと書き出し
- 準備したCSV（10件）を取り込む → 取り込めた件数。
- 連絡先を書き出す（エクスポート）→ どんな項目が入っていたか（メール、名前、タグ など）。

### 作業5：ウェルカムメール3通
- 無料プランで「登録したら自動で3通届く」設定ができるか。
- 記録：**できる / できない**、メモ。

## 記録の送り方

テストが終わったら、このチャットに次のような形で送ってください。Claude がサイト用のデータ（`data/tests/サービス名.json`）にして、TAさんに確認してもらってから公開します。

```
サービス：Kit
日付：2026-12-01
プラン：Free
作業1：25分（つまずき：送信者アドレスの認証で5分迷った）
作業2：できた、10分
作業3：Gmail=プロモーション、Outlook=未テスト、Yahoo=未テスト
作業4：10件取り込めた。書き出し項目：email, first name, tags
作業5：できない（無料プランでは不可）
うまくいかなかったこと：〜
ひとこと：〜
```

## 注意

- 届く場所（メイン・迷惑メールなど）は送るたびに変わることがある。サイトにも「1回のテスト結果」と明記します。
- テスト後のアカウントは消さなくてOK（後で再テストに使えます）。
