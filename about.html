About Newsletter Cost Lab

Newsletter Cost Lab is an independent site run by one developer based in Japan. It isn't owned by, or paid by, any of the platforms it covers.

The aim is simple: help people starting a newsletter see what each platform will really cost, using numbers anyone can check against the vendor's own pricing page, and, from our upcoming tests, how each one performs on the same tasks.

The site's source and data are public on GitHub, so you can see exactly where each number comes from.

Found a wrong price? Please tell us. Corrections are logged in the change log.

Prices last verified against each vendor's own pricing page on 2026-11-14. Vendors change prices without notice. Check the linked pricing page before you buy.
